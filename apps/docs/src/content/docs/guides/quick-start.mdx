# Quick Start

This guide will help you set up Orion and start controlling your Spotify playback in under 5 minutes.

## Prerequisites

Before you begin, make sure you have:

- ✅ Orion installed on your system ([Installation Guide](/guides/installation/))
- ✅ A Spotify account (Free or Premium)
- ✅ Spotify playing on some device (phone, computer, smart speaker, etc.)

<Aside type="tip">
Orion is a **controller** - it needs an active Spotify playback session to control.
Start playing something in Spotify first, then Orion can display and control it.
</Aside>

## Getting Started

<Steps>
1. **Launch Orion**

   Open Orion from your applications menu or desktop shortcut.

2. **Connect to Spotify**

   On first launch, you'll see a "Connect to Spotify" button. Click it to begin authentication.

   ```
   ┌──────────────────────────────────────────┐
   │                                          │
   │        🎵 Welcome to Orion              │
   │                                          │
   │    Connect your Spotify account to       │
   │    start controlling your music.         │
   │                                          │
   │       [ Connect to Spotify ]             │
   │                                          │
   └──────────────────────────────────────────┘
   ```

3. **Authorize access**

   A browser window will open asking you to log in to Spotify. After logging in, click "Agree" to
   authorize Orion.

   ```
   ┌───────────────────────────────────────────────────────────────┐
   │  Spotify                                                       │
   │                                                                │
   │  Orion wants to access your Spotify account                  │
   │                                                                │
   │  This will allow Orion to:                                   │
   │  • View your Spotify account data                             │
   │  • View your activity on Spotify                              │
   │  • Control playback on your devices                           │
   │                                                                │
   │              [ Cancel ]    [ Agree ]                          │
   │                                                                │
   └───────────────────────────────────────────────────────────────┘
   ```

4. **Wait for confirmation**

   After authorizing, you'll see a success page. Orion will automatically detect this and show the
   player interface.

5. **Start playing music**

   If nothing is playing, start a song in Spotify. Orion will display your currently playing track!
</Steps>

## Customization Quick Guide

### Change Theme

1. Right-click anywhere in Orion
2. Hover over "Themes"
3. Select your preferred theme

**Available themes:** Dark, Light, Catppuccin, Dracula, ChatGPT, YouTube, BMW, Milka

### Change Layout

1. Right-click anywhere in Orion
2. Hover over "Layout"
3. Choose from:
   - **Layout A** - Compact (minimal footprint)
   - **Layout B** - Standard (balanced view)
   - **Layout C** - Expanded (large album art)

### Enable Always on Top

1. Right-click anywhere in Orion
2. Click "Always on Top"

This keeps Orion visible above other windows.

## Setting Up AI DJ (Optional)

The AI DJ gives you personalized music recommendations. To set it up:

<Steps>
1. **Open Settings**

   Press `Ctrl+,` (or `⌘+,` on macOS), or right-click → Settings

2. **Go to Connections**

   Navigate to the "Connections" tab

3. **Add an AI Provider**

   Choose from OpenAI, Anthropic, Google AI, or Groq and enter your API key

4. **Activate the Provider**

   Click "Connect" to validate, then set it as **Active**

5. **Use AI DJ**

   Right-click → AI DJ to open the chat interface
</Steps>

### Example AI DJ Conversations

Once configured, try asking:

- "Play something based on my recent listening history"
- "Find me something upbeat and energetic"
- "What's my music taste like?"
- "Play some chill acoustic tracks"

## Troubleshooting First Setup

### Orion won't connect to Spotify

- Ensure you have an internet connection
- Check that your browser can access spotify.com
- Try clearing browser cookies for Spotify

### No track is showing

- Make sure Spotify is playing on some device
- Check that the same Spotify account is used
- Try playing/pausing in Spotify to refresh the connection

### Controls don't work

- Verify you have an active Spotify playback device
- Premium features (like seeking) may be limited on Free accounts
- Try clicking play in Spotify first
